# Snake 3310 — مار نوکیا

بازِ مار کلاسیک نوکیا در مرورگر، با ظاهر صفحات سبز تکرنگ LCD، **تاریخچه امتیازها**، **تنظیم سرعت** و **چهار قیافه مختلف مار**. بدون نصب کتابخانه، بدون سرور و بدون ساخت (build) — فقط سه فایل ساده HTML/CSS/JS.

## قابلیتها

- 🎮 گیمپلی کلاسیک: برخورد با دیوار یا بدن مار = پایان بازی؛ با خوردن هر غذا ۱۰ امتیاز.
- 🏆 **تاریخچه امتیازها**: ذخیره آخرین ۲۰ بازی در `localStorage` به همراه نمایش بهترین امتیاز، میانگین و تعداد بازیها. جدول امتیازها قابل پاک کردن است.
- ⚡ **تنظیم سرعت**: پنج سطح از «آهسته» تا «نهایت» که حین بازی هم قابل تغییرند و ذخیره میشوند.
- 🐍 **قیافه مار**: چهار پوستهٔ «کلاسیک نوکیا»، «پیکسلی»، «گرد و نرم» و «دانههای»؛ پوستهٔ انتخابی ذخیره میشود و در تاریخچه هم ثبت میگردد.
- 🔊 صدای کوتاه (bip) هنگام خوردن غذا و پایان بازی، قابل خاموش/روشن کردن.
- ⌨️ کنترل با کیبورد، دکمههای جهت روی صفحه و کشیدن انگشت (swipe) روی موبایل.
- 💾 تمام تنظیمات و امتیازها در مرورگر ذخیره میشوند و به سرور ارسال نمیشوند.

## نحوه اجرا

سادهترین راه: `index.html` را در مرورگر باز کنید (مثلاً با double-click در VS Code یا File Explorer).

در صورت تمایل به اجرا از طریق سرور محلی:

```bash
cd "Opencode Game"
python3 -m http.server 8000
```

سپس به <http://localhost:8000> بروید.

## کلیدها

| کلید | کار |
| --- | --- |
| `←` `↑` `→` `↓` یا `W` `A` `S` `D` | تغییر جهت مار |
| `Space` / `Enter` | شروع، توقف و ادامه |
| `R` | شروع مجدد |
| دکمه `OK` یا دکمههای جهت | معادل کیبورد، مناسب موبایل |
| کشیدن انگشت روی صفحه | تغییر جهت در موبایل |

## چگونه کار میکند؟

- چرخه بازی با `requestAnimationFrame` و یک شمارندهٔ زمانی (accumulator) پیش میرود؛ فاصلهٔ هر گام بر اساس سرعت انتخابی (۵۰ تا ۲۴۰ میلیثانیه) تنظیم میشود.
- بدن مار به صورت آرایهای از مختصات سلولها نگهداری میشود؛ در هر گام یک سلول جدید اضافه و در صورت عدم خوردن غذا، آخرین سلول حذف میشود.
- رندر روی Canvas با رنگهای کلاسیک LCD (`#9bbc0f`، `#306230`، `#0f380f`) انجام میشود و هر پوسته سبک رسم متفاوتی دارد.
- امتیازها در آرایهای از آبجکت `{score, speed, skin, date}` ذخیره میشوند؛ مرتبسازی بر اساس امتیاز و سپس تاریخ انجام میگردد و فقط ۱۰ رکورد برتر نمایش داده میشوند.
